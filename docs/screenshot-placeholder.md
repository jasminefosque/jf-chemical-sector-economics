# Screenshot Placeholder

To add screenshots to the README:

1. Run the application in development mode: `npm run dev`
2. Take screenshots of:
   - Main dashboard view showing multiple charts
   - Shock event overlay visualization
   - Methodology page
   - Export functionality in action

3. Save screenshots in this directory with descriptive names:
   - `dashboard-overview.png`
   - `shock-events.png`
   - `methodology-page.png`
   - `export-demo.png`

4. Update README.md with actual image paths:
   ```markdown
   ![Dashboard Overview](docs/dashboard-overview.png)
   ```

## Recommended Screenshot Specifications

- Format: PNG
- Resolution: 1920x1080 or higher
- Quality: High (minimize compression)
- Content: Show multiple charts, data, and UI elements
- Annotations: Optional - highlight key features

## Tools

- macOS: Cmd+Shift+4 (selection), Cmd+Shift+3 (full screen)
- Windows: Win+Shift+S (Snipping Tool)
- Linux: gnome-screenshot, flameshot, or similar
- Browser DevTools: Device toolbar for consistent viewport

Ensure screenshots show only synthetic data mode with proper attribution.
